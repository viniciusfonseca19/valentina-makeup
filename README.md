## ✨ Sobre o Projeto

O **Valentina Makeup** é uma landing page moderna, elegante e de alto desempenho desenvolvida sob medida para a marca de maquiagens **Valentina Makeup**. O projeto combina design luxuoso com funcionalidades estratégicas para converter visitantes em clientes — tudo com um clique direto para o **WhatsApp**.

> **"Uma vitrine digital que vende enquanto você dorme."**

---

## 🚀 Funcionalidades

- **Catálogo de Produtos/Serviços** — Apresentação visual e elegante dos produtos da marca
- **CTA para WhatsApp** — Botões de chamada para ação que redirecionam diretamente para o WhatsApp, facilitando o contato e a conversão de clientes
- **Animações fluidas** — Experiência visual premium com animações suaves via Motion
- **Design 100% Responsivo** — Funciona perfeitamente em celulares, tablets e desktops
- **Performance otimizada** — Build rápido com Vite e carregamento ágil para não perder nenhum cliente

## 📦 Como Rodar o Projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/viniciusfonseca19/valentina-makeup.git

# Entre na pasta do projeto
cd valentina-makeup

# Instale as dependências
npm install
```

### Rodando em desenvolvimento

```bash
npm run dev
```

O projeto estará disponível em: [http://localhost:3000](http://localhost:3000)

### Gerando o build de produção

```bash
npm run build
```

### Visualizando o build

```bash
npm run preview
```
